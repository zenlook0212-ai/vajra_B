# 佛典 RAG 使用指南（與 CBETA 線上搜尋對照）

本系統 **不取代** [CBETA Online](https://cbetaonline.dila.edu.tw/) 全文檢索，而是：用自然語言問義理，從已匯入語料中檢索相關段落，並附 **CBETA 坐標** 與綜合說明。

---

## 何時用「qwen35b · 佛典RAG」

| 適合 | 範例 |
|------|------|
| 用白話問佛典義理 | 「佛經中如何說十二因緣？」 |
| 要**可讀綜述**且能點坐標回原文 | 義理面向 + 綜合回答 + `【T…】` |
| 不確定經名、只知概念 | 「四諦」「緣起」「淨土」 |
| 問某部經的內容／出處 | 「長阿含經序提到幾種法教？」 |

**請開新對話**，並確認模型為 **qwen35b · 佛典RAG**（含 `search_tripitaka` 工具）。

---

## 何時改用 CBETA 線上搜尋

| 適合 | 範例 |
|------|------|
| 要**列齊**所有命中段落 | 全藏搜「十二因緣」每一處（或見下方 **全藏出處** 工具） |
| 已知經名、卷、頁、行 | 直接開 T02n0099 |
| 關鍵字考據、編目、寫論文附錄 | 精確字面比對 |
| 不要 AI 綜述，只要原文 | 自己讀、自己判斷 |

👉 [CBETA Online](https://cbetaonline.dila.edu.tw/) 關鍵字／進階搜尋仍是最完整的**全藏索引**。

---

## 本系統實際做什麼（與「找全藏」的差別）

```
你的問題 → 語義 + 關鍵詞檢索 → 取最相關的若干段（非全部）
         → 摘錄原文 + CBETA 坐標 →（可選）LLM 寫綜合回答
```

| | **佛典 RAG** | **CBETA 全文搜尋** |
|---|-------------|-------------------|
| 輸入 | 自然語問句 | 關鍵詞、經目 |
| 輸出 | 2～4 個面向 + 綜述 + 連結 | 命中列表（可很多條） |
| 覆蓋 | **最相關** top 段 | **盡可能全** |
| 幻覺 | 以坐標約束；無坐標會被擋 | 無（只顯示原文） |
| 速度 | 約十幾秒～1 分鐘 | 通常較快（列表） |

**設計目標**：像**帶出處的研究助理簡答**，不是第二套全藏 grep。

## 回答長什麼樣（D 類開放義理）

預設 **hybrid** 合成：

1. **【義理面向】** — 自檢索語料摘錄，每段附 `【Txxnxxxx_p…】`（坐標可靠）
2. **【綜合回答】** — 模型整合義理關聯（僅引用上列已有坐標）
3. **CBETA 連結** — 點進原典

義理題回答末尾會自動附 **「還有哪些經提及…」** 精簡表（可關：`VAJRA_RAG_SURVEY_TEASER=0`）；完整列表用 `list_tripitaka_occurrences`。

**Teaser 與正文為何不同？** 【義理面向】來自本輪 **語義 top-k**（最相關少數段）；末尾 teaser 來自 **關鍵詞全語料統計**（如 T30N1579 段數多但未必進 top-k）。兩者並列是設計如此，非漏引。

若只出現 2～3 個面向，代表**本輪檢索最相關**的經典段落，不代表全藏只有這幾處。

## 模型怎麼選

| 模型 | 用途 |
|------|------|
| **qwen35b · 佛典RAG** | 佛典、CBETA、大藏經考據（**請用這個**） |
| **qwen35b · 深度推理** | 一般難題；**無** CBETA 檢索，佛典題會提示改用佛典RAG |

若回答出現英文譯名、`T06, No. 378` 式經號且**沒有** `【T…】`，多半是未走檢索；請換佛典RAG 並重問。

## 全藏出處（`list_tripitaka_occurrences`）

若問題是「**十二因緣還有哪些經**」「**列出全藏出處**」，請用同一模型下的 **`list_tripitaka_occurrences`** 工具（或明確說「列出出處表」）。

- 在**已匯入 pgvector 語料**內做 BM25／關鍵詞搜尋，按經典 `canon_id` 分組
- 每部經附 1～2 段樣本坐標 + **CBETA 連結**
- **分頁**：`list_tripitaka_occurrences(keyword="四諦", page=2)`（每頁 15 部經）
- **不**做 LLM 綜述，速度較快（通常數秒）
- 仍**不等於** CBETA 官網全庫；要盡可能全的逐條索引請用 CBETA Online

範例問法：「列出語料中『四諦』出現在哪些經」→ 工具 `keyword=四諦`。

## 一句話

- **要懂、要綜述、要坐標** → `search_tripitaka`（佛典 RAG）  
- **要經目列表、看還有哪些經** → `list_tripitaka_occurrences`（全藏出處）  
- **要全、要逐條、要自己讀原文** → CBETA 線上搜尋  

三層搭配使用效果最好。
